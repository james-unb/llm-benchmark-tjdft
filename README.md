# Exam Papers and Answer Keys Collection

This repository contains historical exam papers and answer keys organized by year.

## Repository Structure

```
llm-benchmark-tjdft/
├── data/
│   ├── raw/
│   │   ├── provas/                         # original exam PDFs
│   │   └── gabaritos/                      # original answer key PDFs
│   ├── interim/
│   │   ├── txt/                            # text extracted from the PDFs
│   │   └── provas_tjdft.csv                # parsed questions
│   └── processed/
│       └── provas_tjdft_com_gabarito.csv   # final dataset (questions + answers)
└── src/
    ├── parser_prova_2014_2015.py
    └── gabaritos.py
```

- **`data/raw/`**: original files; they should not be modified.
- **`data/interim/`**: intermediate files generated by the scripts. They can be regenerated at any time and help debug the extraction.
- **`data/processed/`**: final dataset consumed by the benchmark.

To regenerate the intermediate and processed data:

```bash
python src/parser_prova_2014_2015.py   # data/raw/provas -> data/interim
python src/gabaritos.py                # data/interim -> data/processed
```
